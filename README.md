# 拼多多订单导出工具

一键把拼多多（多多）**买家订单**导出为 Excel（.xlsx）/ CSV 文件。
包含商品名称、单价、实付金额、应付金额、物流、店铺、下单时间等 45 个字段。

---

## 一、目录结构

```
拼多多订单导出工具/
├── 拼多多订单导出工具.exe    ← 免安装版，双击直接用（无需 Python）
├── 启动导出工具.bat          ← 源码版启动入口（需 Python）
├── README.md                 ← 本说明

├── 程序/                     ← 程序源码

│   ├── pdd_order_export.py   # 命令行入口
│   ├── config.json           # 配置文件
│   └── webui/                # 界面文件
└── 登录助手扩展/             ← 浏览器扩展（可选，自动抓凭证）
    └── manifest.json 等
```

## 二、运行方式（二选一）

### 方式 1：免安装版（推荐，最简单）

**双击 `拼多多订单导出工具.exe`** 即可，无需安装 Python、无需装任何依赖。
浏览器会自动打开登录界面。

> 适合拷贝到 U 盘、发给朋友、在没装 Python 的电脑上直接使用。

### 方式 2：源码版（需要 Python）

**双击 `启动导出工具.bat`**，脚本会自动检测 Python、安装依赖并启动界面。

## 三、使用步骤

### 第 1 步：获取登录凭证

导出需要两个凭证：**多多号（pdd_user_id）** 和 **登录凭证（PDDAccessToken）**。

用「登录助手扩展」（推荐，自动抓取）

1. 打开 Edge，地址栏输入 `edge://extensions/`
2. 打开右上角「开发人员模式」
3. 点「加载解压缩的扩展」，选择本目录下的 `登录助手扩展` 文件夹
4. 点工具栏「拼多多登录助手」图标 →「打开拼多多登录页」→ 完成登录（验证码/扫码）
5. 登录成功后扩展自动显示凭证，一键复制

### 第 2 步：启动并导出

1. 双击 `拼多多订单导出工具.exe`（或 `启动导出工具.bat`）
2. 浏览器自动打开登录界面（若未打开，手动访问 `http://127.0.0.1:8765/`）
3. 粘贴「多多号」和「登录凭证」→ 点「登录」
4. 选择订单类型 / 时间范围 / 格式 → 点「开始导出」
5. 完成后点「打开导出文件夹」，导出文件在 `程序/output/` 目录

## 四、依赖要求

| 项 | 要求 |
|----|------|
| 操作系统 | Windows 7 及以上 |
| Python | 3.8+（**仅源码版需要**，exe 版无需） |
| Python 库 | `requests`、`openpyxl`、`pycryptodome`（启动脚本自动安装） |
| 浏览器 | Edge / Chrome（仅登录用） |

> exe 免安装版已打包全部依赖，无需 Python；源码版首次运行会自动装依赖。

---

## 五、命令行方式（可选）

```bash
cd 程序
python pdd_order_export.py --pdduid <多多号> --token <凭证> --format xlsx
```

常用参数：`--type 1~5`（订单类型）、`--from/--to`（时间）、`--format xlsx/csv/both`、`--dump`（调试）。

---

## 六、常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| 双击 bat 提示 Python not found | 未装 Python 或未勾选 PATH | 重装 Python 并勾选 Add to PATH |
| 打开界面但导出 0 条 | 凭证失效或风控 | 重新登录获取凭证；等 1~2 小时再试 |
| 提示 424 / 风控错误 | 请求过频繁触发拼多多风控 | 停止操作，等 1~2 小时；或换网络 |
| 收货人姓名/电话是空的 | 订单列表接口本就不返回收货人 | 属正常现象 |
| 条数不对 | 翻页异常 | 用 `--dump` 打印响应，对照 `程序/field_mapping.py` |
| 凭证过期 | 登录态失效 | 重新登录获取新凭证 |

## 七、便携说明（U 盘使用）

- 整个文件夹可直接拷到 U 盘，在其他 Windows 电脑使用；
- **免安装版**（`拼多多订单导出工具.exe`）无需任何配置，双击即用；
- **源码版**在其他电脑首次使用需先装 Python（见依赖要求），之后双击 bat 即可；
- 导出的文件保存在 `程序/output/` 目录，随 U 盘带走即可。
